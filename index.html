🧭 My-CPI 데이터 탐구 수업의 전체 구성과 흐름

본 수업은 단순한 지수 공식 암기를 넘어, ‘측정(CPI)’ ➔ ‘검증(통계)’ ➔ ‘미래 적용(연금)’이라는 일관된 데이터 분석 여정을 통해 진행됩니다. 상단의 각 차시 탭이나 카드의 바로가기 버튼을 클릭하여 단계별 탐구를 시작해 보세요.

[1단계] Ⅰ. CPI (0~1차시) 물가를 어떻게 하나의 숫자로 만드는지 품목·가중치·가중평균의 원리를 배우고 나의 소비장부로 My-CPI를 계산합니다.
[2단계] Ⅱ. 통계 (2~4차시) 이 숫자로 어디까지 말할 수 있는지 학급 데이터의 왜곡도·이상치를 점검하고, 비선형 복리 감쇄와 과거 변동성 시나리오를 검증합니다.
[3단계] Ⅲ. 연금 (5차시 확장) 미래를 어떻게 준비할 것인지 물가 상승 시나리오를 화폐의 시간가치($FV$)와 복리 준비금 산식에 직접 대입하여 실생활에 적용합니다.

가중평균 물가지수 산출 수식 교과서 외

$$\text{단순평균: } \bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$$

$$\text{가중평균: } \bar{x}_w = \frac{w_1x_1 + w_2x_2 + \cdots + w_nx_n}{w_1 + w_2 + \cdots + w_n} = \frac{\sum_{i=1}^{n} w_i x_i}{\sum_{i=1}^{n} w_i}$$

(여기서 $w_i$는 품목별 가중치(비중), $x_i$는 품목별 물가상승률)

이상치 판별식 및 왜곡도 공식 교과서 (이상치)교과서 외 (왜곡도)

$$\text{사분위수범위: } IQR = Q_3 - Q_1$$

🧮 핵심 수식

미래 생활비 및 복리 적립식 준비금 공식 경제수학 (원리합계)

$$\text{미래 월 필요 생활비: } FV = PV \times (1 + r)^n$$

$$\text{정기 적립 미래가치 (연금): } S_n = M \times \frac{(1 + i)^n - 1}{i}$$

($PV$: 현재 월 생활비, $r$: 물가상승률, $n$: 경과 년수, $M$: 연간 적립액, $i$: 수익률)
